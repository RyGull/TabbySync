# Contributing

**TabbySync does not accept code contributions.** Pull requests will be closed
without merging — please don't spend your time on one.

This isn't hostility, it's licensing: TabbySync is source-available under a
[proprietary licence](LICENSE) and Ryan Gulliver is the sole copyright holder.
Merging someone else's code would split that ownership and make it impossible to
change the project's licence later without tracking down every past contributor.
Keeping it single-author keeps those options open.

## What is welcome

- **Bug reports.** Especially anything involving data loss, a failed merge, a
  sync that overwrote something, or an encryption/passphrase problem. Include
  your browser and version, the sync method (self-hosted / GitHub Gist /
  JSONBin.io), the TabbySync version from `manifest.json`, and what you expected
  versus what happened.
- **Feature suggestions.**
- **Security reports.** The source is published precisely so it can be audited.
  If you find something, please report it privately rather than opening a public
  issue.

Reports and suggestions are not contributions under Section 3 of the licence —
sending one costs you nothing and grants nothing.

## What you may do with the code

Read it and audit it — anyone may, for any purpose. You may also run it and
modify your own copy, free of charge, for your own personal use. You may not use
it for a commercial purpose, redistribute it (modified or not), or publish it to
any extension store. See [LICENSE](LICENSE) for the exact terms.
