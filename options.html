2 Don't have that file yet?

TabbySync writes it for you, with a fresh access code already inside. Takes about three minutes, and you only do it once.

  1. Download it.
  2. Upload the whole tabbysync folder to your web space — the same place your website's pages live (on cPanel that's usually public_html/). Your web address must start with https://.
  3. Come back up to step 1 and paste the address of the uploaded file, e.g. https://example.com/tabbysync/tabbysync.php, then click the button below to fill in the access code for you.
  4. Click “Save and connect”, then “Check it works”. Repeat the same address, code and group name on your other computers.

Setting this up

GitHub gives every account a place to keep small private files, called a gist. TabbySync makes one for you and keeps your bookmarks and tabs in it. You need a free GitHub account and one “access token”, which is a password that only lets TabbySync touch those files and nothing else.

Worth knowing first. A private gist is unlisted, not truly locked: anyone who gets its direct link, or your token, can read it. GitHub can read it too. That's why the password lock — the next step on the settings page — matters much more here than it does on your own website. Turn it on.

Make the token

  1. Sign in at github.com. If you don't have an account, make one — it's free.
  2. Go to github.com/settings/personal-access-tokens/new. (The long way round: click your picture, top right → Settings → scroll to Developer settings at the bottom of the left menu → Personal access tokens → Fine-grained tokens → Generate new token.)
  3. Token name — type anything you'll recognise later, like TabbySync.
  4. Expiration — choose No expiration. TabbySync can't renew a token by itself, so an expiring one means sync quietly stops working on the day it lapses until you make a new one.
  5. Repository access — leave it exactly as it is. Gists aren't repositories, so this setting has no effect either way.
  6. Permissions — this is the only part that matters. Find the Account permissions section, click Gists, and set it to Read and write. Don't grant anything else; TabbySync needs nothing else.
  7. Click Generate token at the bottom.
  8. GitHub shows the token once, as a long line starting github_pat_. Copy it now — you can't see it again, only replace it.

Put it into TabbySync

  1. Back on this page, paste it into GitHub access token.
  2. Fill in Name for this group of computers — any word, e.g. home. Use the same word on your other computers to share the same data.
  3. Turn on the password lock — the next step on the settings page — and pick a password. GitHub then only ever stores scrambled text it cannot read.
  4. Click Save and connect, then Check it works. TabbySync creates the private gist the first time it saves — you don't need to make one yourself.

If something goes wrong

  • “GitHub rejected the token” — the Gists permission is missing or set to read-only. Make a new token with it set to Read and write.
  • Sync stopped after a while — the token expired. Make a new one and paste it in.
  • You want it gone — delete the token at github.com under the same Settings page, and use Advanced and delete options at the bottom of this page to remove the data.

JSONBin.io is a free service that stores small files, called bins. TabbySync makes the bins for you; all you have to fetch is one key. There is no server to run and nothing to upload.

Worth knowing first. This is the least private of the three choices: your data sits on a free third-party service with no promises about how long it keeps things, and free bins can be rate-limited or reclaimed. Turn on the password lock — the next step on the settings page — so JSONBin only ever holds scrambled text, and don't use this option for anything sensitive.

Get the key

  1. Go to jsonbin.io and sign up, or log in if you already have an account. The free plan is enough.
  2. Click your account name in the top-right corner and choose API Keys.
  3. You'll see a key labelled X-Master-Key. Click to reveal it, then copy it. If there isn't one yet, click to create it first.

Put it into TabbySync

  1. Back on this page, paste it into JSONBin API key.
  2. Name for this computer is only a label for you — it doesn't change where anything is stored. This method keys everything off the API key itself, so one key means one profile; use your own website or GitHub if you want separate work and home sets.
  3. Turn on the password lock — the next step on the settings page — and pick a password.
  4. Click Save and connect. The bins are created the first time it saves, which is also when the key is really checked — so “Check it works” has nothing to test until then.

If something goes wrong

  • Saving fails right after you paste the key — the key is wrong, or it was copied with a space on the end. Copy it again from the API Keys page.
  • It worked and then stopped — free accounts have request limits. Raising the “check for changes every” minutes in step 4 makes TabbySync ask far less often.
