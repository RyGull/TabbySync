🛠️ Self-hosting — generate your server files

No endpoint yet? Generate a ready-to-upload bundle (one PHP script + .htaccess guards) with a fresh random token. It runs on your web space; SyncLocker never sends your data to anyone.

How to host it (about 3 minutes)
  1. Click Download server files — you get synclocker-server.zip containing a synclocker/ folder.
  2. Upload that whole folder to your PHP web space (e.g. public_html/ on cPanel) over HTTPS.
  3. Set Server URL above to https://YOURDOMAIN/synclocker/synclocker.php, then click Use this token above.
  4. Save & grant access, then Test connection — a 404 is expected until the first sync creates a file.
  5. Repeat the same URL + token + sync name on your other computers.
